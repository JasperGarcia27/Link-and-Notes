Installation of Project

- install laragon

- put "php-8.2.20-nts-Win32-vs16-x64" inside of "C:\laragon\bin\php"

- change php version on Laravel 
	- menu\PHP\Version

- put the project inside of "C:\laragon\www"

- click start all


- in browser put {ip address of the device}\{project folder name}

- inside the laravel project put this on terminal (gitbash) "php artisan config:clear"
- make sure that have the proper db on web server

- you may check also the php path 
	- click windows + S and type "edit the system environment variables"
	- click "Environment Variables..."
	- choose "path" and click edit
	- then browse it if is the php path is there else click new
	- then click all ok
	- restart the terminal/vs code
