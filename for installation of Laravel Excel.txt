for installation of Excel "use Maatwebsite\Excel\Facades\Excel;"

1. Install Laravel Excel
	Inside your Laravel project folder run:
	-  composer require maatwebsite/excel

2. Verify installation
	composer show maatwebsite/excel

3. Add the import in Controller
	use Maatwebsite\Excel\Facades\Excel;

	In Controller
	<?php

	namespace App\Http\Controllers;

	use Illuminate\Http\Request;
	use Maatwebsite\Excel\Facades\Excel;   // <--- This must exist

	class PayrollController extends Controller
	{
    	      //
	}
4. Clear Laravel caches
	- php artisan config:clear
	- php artisan cache:clear
	- php artisan optimize:clear
	- composer dump-autoload
